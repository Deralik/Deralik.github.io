## Invariants (owner-agreed 2026-08-02 — hold across every direction)

- Nothing moves and nothing decorates unless it demonstrates something
  true about the work; every animation is evidence.
- Every number traces to BRIEF.md's fact packs; demos, comparisons, and
  illustrations carry honest labels stating exactly what is running.
- Base experience is fast static pages, readable without JS; every
  interactive element degrades to a poster/still. No scroll hijacking.
- Project order is positioning (research first) in every layout.
- "Add a section" (publication, talk, project) is a boring, first-class
  operation — no redesign to extend.
- Each research page hero (cINR, GRTCache) is a demo slot: poster/clip
  of the demo's own dataset now, the in-browser demo later, replaced in
  place without relayout.
