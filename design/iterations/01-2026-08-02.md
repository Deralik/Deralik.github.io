## Concepts proposed (details in conversation)

- **A — Convergence** ("the site resolves"): one interaction grammar — a
  scrubber over real frame/artifact series — reused with a different
  meaning per project (samples, LOD, build days, releases, curriculum
  stages). Transitions = re-projection (shared element persists, rest
  re-converges).
- **B — Instrument language**: plates, calibrated axes, monospace
  numerals, measured captions; site-wide provenance motif — every number
  can draw a hairline to its source. Look/system layer, composable.
- **C — Five rooms**: home as a continuous walk through five full-bleed
  atmospheres derived from each project's real material; threshold
  transitions shift the palette; pages are rooms expanded.
- **D — Abstract live index**: small self-written canvas/SVG kinetics,
  one per project, each animating the project's core *idea* (cache paging
  around a cursor; splats consolidating under few updates; dependent bars
  reflowing; a two-way sync that refuses to destroy; a pose graph
  relaxing). Labeled as illustrations, never as the software.
- **Recommended synthesis**: D for the home index + B as the page
  language + A's scrubber only where a real series exists + view-
  transition morphs and threshold footers for movement.
